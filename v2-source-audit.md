# v2 open-data and licensing audit

**Review date:** 2026-10-10  
**Status:** preliminary source screen; no new factor source is cleared for integration. The existing Carbonfact v1.1.0 release remains the only bundled source. No candidate dataset archive or new factor values were added to the repository.

This audit is an eligibility screen, not a finding that every source in a collection has been exhaustively verified. Dataset-level metadata is not a substitute for checking the exact files, their upstream providers, and the rights for each dependency.

## Integration gate

Before adding any factor data, the selected version and files must have:

1. Explicit rights to redistribute the exact data and any derived values, plus required attribution and share-alike notices.
2. A recorded version, source citation, geography, temporal coverage, declared/reference unit, and process boundary.
3. A documented provider/dependency graph and method. For any new v2 factor integration, do not acquire, bundle, query, or reconstruct ecoinvent data or use ecoinvent provider links. The already-pinned Carbonfact published scores remain unchanged and are outside this source-integration screen.
4. Indicator definitions, characterization method, and units that can be used without presenting an unmatched process or indicator as equivalent to the existing EF 3.1 factors.
5. Reproducible values and provenance at the individual process/indicator level. No inferred quantities, product total, or combined score.

## USDA collection finding

The USDA collection merits further review: it contains an actual cotton field-crop unit-process inventory, not merely a blank modeling template. Its public-domain label and open process files make version 2 a possible *foreground LCI* candidate, but do not make it a complete impact-factor dataset. The separate version-1 crosswalk explicitly points to ecoinvent 2.2; that crosswalk is excluded. The version-2 archive’s complete provider graph has not been inspected, so it is not yet possible to certify that a calculation based on it can be completed without a non-open dependency. No values have been mapped to an apparel input or added to the API.

## Result and next step

No newly reviewed source passes the complete licensing, provenance, boundary, and method gate for factor integration. Continue with the version-2 USDA file-level dependency audit and the exact reuse terms for the 2026 cotton studies. Only after those checks pass should a separate factor-integration proposal be made, with source version, geography, time coverage, unit, boundary, provider graph, per-indicator method, attribution, and test fixtures documented. Until then, keep the input organizer as user-declared browser-only context and keep every existing result separate.
